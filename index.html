Cài đặt API Key

NgoThang_video dùng một API Key chung do chủ ứng dụng cấu hình. Bạn, vợ bạn và những người mở cùng đường link sẽ dùng chung khóa; không cần nhập API trên từng thiết bị.

ⓘ
Cách cấu hình một lần
  1. Mở repository GitHub của NgoThang_video.
  2. Mở file config.js và nhấn biểu tượng bút chì (Edit).
  3. Thay nội dung giữ chỗ trong dòng YOUTUBE_API_KEY bằng API Key mới của bạn, giữ nguyên dấu ngoặc kép.
  4. Nhấn Commit changes. Sau khi GitHub Pages cập nhật, tất cả người dùng đều dùng được.
!
Lưu ý về quyền riêng tư

Vì chỉ dùng GitHub Pages, API Key chung được gửi tới trình duyệt và người truy cập có thể xem được. Hãy giới hạn khóa chỉ cho YouTube Data API v3 và Website restrictions của domain GitHub Pages. Không dùng khóa này cho dịch vụ khác.

Mở Google Cloud để kiểm tra giới hạn khóa. Không sử dụng lại API Key đã gửi trong chat trước đây.
