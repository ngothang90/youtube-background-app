Đưa app lên GitHub – không dùng Vercel

Chỉ cần GitHub để lưu mã nguồn và xuất bản website miễn phí. Không cần cài Node.js, không cần sửa code.

Trước khi bắt đầu: thay API Key cũ

API Key bạn đã gửi trong cuộc trò chuyện cần được coi là đã lộ. Hãy xóa/rotate khóa cũ và tạo khóa mới trong Google Cloud. Không gửi khóa mới vào chat, không ghi khóa vào file và không tải khóa lên GitHub.

Google Cloud Credentials ↗YouTube Data API v3 ↗
  1. Chọn đúng Google Cloud Project của bạn.
  2. Đảm bảo YouTube Data API v3 đã bật.
  3. Tạo API Key mới.
  4. Trong API restrictions, chọn Restrict key và chỉ chọn YouTube Data API v3.
  5. Tạm thời chưa cần cài Website restrictions. Sau khi có địa chỉ GitHub Pages, quay lại thêm domain ở bước 4.
Không sử dụng lại khóa cũ đã gửi trong chat.

Bước 1 – Tạo repository GitHub

  1. Mở GitHub và đăng nhập.
  2. Nhấn nút New repository.
  3. Đặt tên chính xác: NgoThang_video.
  4. Chọn Public để GitHub Free xuất bản bằng GitHub Pages.
  5. Nhấn Create repository.
  6. Giải nén file ZIP. Mở thư mục dự án, chọn toàn bộ file và thư mục con (ví dụ index.html, app.js, styles.css, assets...), rồi kéo thả vào trang repository → Add file → Upload files.
  7. Nhấn Commit changes.
Tạo repository GitHub ↗
Các tệp được tải lên phải nằm ngay ở thư mục gốc repository. Khi mở repo, bạn phải nhìn thấy index.html ngay ở màn hình đầu tiên, không nằm trong thêm một thư mục lồng bên trong.

Bước 2 – Bật GitHub Pages

  1. Trong repository NgoThang_video, mở tab Settings.
  2. Ở menu bên trái, chọn Pages.
  3. Tại phần Build and deployment, chọn Source: Deploy from a branch.
  4. Branch chọn main; thư mục chọn /(root).
  5. Nhấn Save.
  6. Đợi GitHub xuất bản xong, trang Pages sẽ hiện đường link website dạng bên dưới.
https://TEN_GITHUB_CUA_BAN.github.io/NgoThang_video/
Hướng dẫn chính thức GitHub Pages ↗
Khi có đường link trên, website đã chạy trên GitHub. Không cần Vercel.

Bước 3 – Giới hạn API Key theo website

Quay lại Google Cloud → APIs & Services → Credentials → bấm vào API Key mới.

  1. Application restrictions chọn Websites.
  2. Thêm địa chỉ, thay TEN_GITHUB_CUA_BAN bằng tên tài khoản GitHub thật của bạn:
https://TEN_GITHUB_CUA_BAN.github.io/*

API restrictions vẫn chỉ chọn YouTube Data API v3. Nhấn Save.

Vì GitHub Pages là website công khai, người khác có thể xem mã nguồn. Khóa không có trong mã nguồn mà được bạn tự nhập trong từng trình duyệt. Giới hạn domain giúp giảm việc website khác sử dụng khóa của bạn, nhưng không biến API Key thành bí mật tuyệt đối.

Bước 4 – Nhập API Key trong ứng dụng

  1. Mở website GitHub Pages vừa xuất bản.
  2. Nhấn biểu tượng bánh răng ⚙ ở góc trên.
  3. Dán API Key mới vào ô YouTube API Key.
  4. Nhấn Lưu API Key.
  5. Thử tìm một từ khóa, ví dụ “nhạc thư giãn”.
API Key được lưu trong bộ nhớ của trình duyệt trên thiết bị hiện tại; không cần thêm key vào GitHub. Trên iPhone và máy tính, bạn nhập cùng key một lần trên mỗi thiết bị.

Bước 5 – Cài như ứng dụng trên điện thoại

iPhone: mở website bằng Safari → Chia sẻ → Thêm vào màn hình chính → bật Mở dưới dạng ứng dụng web nếu tùy chọn xuất hiện → Thêm.

Android: mở bằng Chrome → menu ⋮ → Cài đặt ứng dụng / Add to Home screen.

Máy tính: dùng nút Cài ứng dụng hoặc biểu tượng Install của trình duyệt nếu có.

PWA có thể mở ở cửa sổ riêng. YouTube Embedded Player vẫn theo giới hạn của YouTube, không phát nền khi ứng dụng bị thu nhỏ/đóng.

Nếu tìm kiếm chưa chạy

  • API key không hợp lệ: kiểm tra đã dùng khóa mới, đúng Google Project và đã bật YouTube Data API v3.
  • Referer blocked: kiểm tra URL Website restrictions phải là domain GitHub Pages đúng của bạn.
  • Quota exceeded: YouTube Data API có mặc định 100 lượt gọi search.list mỗi ngày cho mỗi project. App lưu cache để giảm số yêu cầu.
  • Trang trắng hoặc lỗi 404: kiểm tra index.html nằm ngay ở thư mục gốc repo, Branch main và /(root) được chọn trong Pages.
