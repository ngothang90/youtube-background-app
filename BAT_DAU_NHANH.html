Hướng dẫn đưa ứng dụng lên mạng

Làm theo từng bước. Bạn không cần sửa code và không cần cài phần mềm lập trình.

1

Trước tiên: thay API Key bạn đã gửi trong cuộc trò chuyện

Vì mã trước đã được chia sẻ trong chat, hãy coi nó là mã đã lộ. Trong Google Cloud Console, mở APIs & Services → Credentials, chọn key cũ và xóa/rotate key đó. Tạo một API Key mới cho NgoThang_video. Không gửi key mới vào chat và không ghi key vào file ZIP.

Mở Google Cloud Credentials ↗ YouTube Data API v3 ↗
  1. Đảm bảo YouTube Data API v3 đã được bật.
  2. Vào Credentials và tạo API Key mới.
  3. Trong API restrictions, chọn Restrict key và chỉ bật YouTube Data API v3.
  4. Vì key được dùng ở server Vercel, không đặt Website/HTTP referrer restriction. Chỉ đặt IP restriction nếu bạn có IP egress tĩnh của máy chủ.
Giữ API Key mới ở nơi riêng tư. Khi đến bước 4, bạn sẽ dán key vào Vercel. Không dán vào README, JavaScript, HTML hoặc GitHub.
2

Tạo nơi lưu mã nguồn trên GitHub

GitHub sẽ lưu các file ứng dụng. Tạo một repository mới, tên đúng như sau:

NgoThang_video
  1. Đăng nhập GitHub.
  2. Nhấn New repository.
  3. Nhập tên NgoThang_video.
  4. Chọn Private để giữ mã nguồn riêng tư trong giai đoạn thử nghiệm.
  5. Nhấn Create repository.
  6. Giải nén file ZIP NgoThang_video_v0.2.0.zip trên máy tính. Mở thư mục NgoThang_video bên trong, chọn toàn bộ file và thư mục con rồi tải lên repository bằng Add file → Upload files.
  7. Nhấn Commit changes để lưu.
Chỉ tải file trong thư mục dự án đã giải nén. Không tạo file `.env.local` và không tải API Key lên GitHub. File mẫu `.env.example` không chứa key thật.
Tạo repository GitHub ↗
3

Đưa repository GitHub lên Vercel

  1. Mở Vercel và đăng nhập bằng GitHub.
  2. Nếu được hỏi, cho phép Vercel truy cập repository NgoThang_video.
  3. Ở trang Add New → Project, tìm repository NgoThang_video rồi nhấn Import.
  4. Trong phần cấu hình, để Framework Preset là Other, Root Directory là ./.
  5. Không cần Build Command; không cần Output Directory. Giữ các thiết lập mặc định còn lại.
  6. Nhấn Deploy. Đợi Vercel tạo domain dạng `...vercel.app`.
Mở Vercel – New Project ↗
4

Thêm API Key vào đúng vị trí trong Vercel

Trong Vercel Dashboard, mở project NgoThang_video → Settings → Environment Variables → Add New.

NameYOUTUBE_API_KEY
ValueDán API Key mới lấy từ Google Cloud vào ô này. Không gửi key qua chat.
EnvironmentChọn Production. Chọn thêm Preview nếu muốn kiểm tra bản thử.

Nhấn Save. Sau đó vào Deployments, chọn deployment mới nhất và nhấn nút ba chấm → Redeploy. Có thể bỏ chọn “Use existing Build Cache” nếu giao diện Vercel hiển thị tùy chọn này.

Đây là bước duy nhất bạn cần dán API Key. Code đã đọc biến YOUTUBE_API_KEY ở máy chủ; key không được gửi xuống trình duyệt.
Mở Vercel Dashboard ↗
5

Kiểm tra app đã nhận API Key chưa

Thay `TEN-DU-AN` bằng domain Vercel của bạn rồi mở đường dẫn kiểm tra sau:

https://TEN-DU-AN.vercel.app/api/health

Nếu cấu hình đã được nhận, bạn sẽ thấy kết quả gần giống:

{"ok":true,"app":"NgoThang_video","youtubeApiKeyConfigured":true}

Đây chỉ kiểm tra biến môi trường đã có mặt, không tiết lộ key và chưa xác nhận key có quyền gọi YouTube. Tiếp theo mở trang chính, tìm thử `nhạc thư giãn`.

Hoàn tất khi bạn thấy danh sách video và nhấn vào ảnh video để phát bằng YouTube Player chính thức.

Xử lý lỗi thường gặp

  • youtubeApiKeyConfigured: false: tên biến phải chính xác là `YOUTUBE_API_KEY`; kiểm tra đã Save và chọn Production; sau đó Redeploy.
  • API Key không hợp lệ: kiểm tra không dán thừa dấu cách, dùng key mới và thử lại.
  • accessNotConfigured: bật YouTube Data API v3 trong đúng Google Cloud Project chứa API Key.
  • ipRefererBlocked: xem lại Application restrictions; không dùng HTTP referrer restriction cho request server-side Vercel.
  • quotaExceeded: đã hết hạn mức tìm kiếm hàng ngày của YouTube Data API. Đợi hạn mức được làm mới hoặc kiểm tra hạn mức trong Google Cloud.
  • Video không phát trong khung: một số chủ video không cho nhúng hoặc có giới hạn khu vực/độ tuổi. Bấm “Mở YouTube” trên thẻ video.
YouTube Data API mặc định có 100 lượt gọi `search.list` mỗi ngày. App dùng cache để giảm số lần gọi; mỗi lần bạn chủ động tìm kiếm mới có thể tiêu thụ một lượt.

Cài app trên điện thoại sau khi website chạy

iPhone: mở domain bằng Safari → Chia sẻ → Thêm vào màn hình chính → bật “Mở dưới dạng ứng dụng web” nếu tùy chọn này hiện ra → Thêm.

Android: mở domain bằng Chrome → menu ⋮ → Cài đặt ứng dụng / Add to Home screen.

Máy tính: dùng biểu tượng Install trên thanh địa chỉ hoặc menu trình duyệt.

PWA vẫn dùng trình phát YouTube chính thức; video YouTube không được app tiếp tục phát nền khi bị thu nhỏ/đóng. Mở biểu tượng app sẽ không hiện thanh địa chỉ trình duyệt nếu trình duyệt/hệ điều hành cài web app ở chế độ standalone.
