Quan trọng — không làm mất API Key

Đây là gói cập nhật cho repository đang chạy. ZIP không chứa file config.js, vì vậy API Key dùng chung đang có trên GitHub sẽ được giữ nguyên. Khi tải file lên GitHub, không xóa hoặc tạo lại config.js.

Không đưa API Key vào tin nhắn hoặc gửi cho người khác. Nếu API Key cũ từng bị chia sẻ, hãy thu hồi và dùng khóa mới.

Bước 1 — cập nhật file trên GitHub

  1. Tải ZIP cập nhật, giải nén trên máy tính.
  2. Mở repository NgoThang_video trên GitHub.
  3. Chọn Add file → Upload files.
  4. Kéo các file và thư mục trong gói đã giải nén vào GitHub. Cho phép ghi đè file trùng tên như index.html, app.js, styles.css, sw.js.
  5. Đảm bảo không xóa hoặc ghi đè config.js. Gói cập nhật không có file này.
  6. Nhấn Commit changes.

Bước 2 — kiểm tra Website restrictions

Đây là nguyên nhân thường gặp khi API Key đã nhập nhưng không tìm kiếm được. Trong Google Cloud → APIs & Services → Credentials → chọn API Key → Application restrictions → Websites, thêm cả hai dòng dưới đây và thay username thật của bạn:

https://TEN_GITHUB_CUA_BAN.github.io
https://TEN_GITHUB_CUA_BAN.github.io/*

Không chỉ thêm riêng /NgoThang_video/*. Ứng dụng gửi referrer ở cấp domain khi gọi Google API nên Google chỉ nhận domain gốc.

Trong API restrictions, chọn Restrict key → YouTube Data API v3, sau đó Save.

Bước 3 — làm mới ứng dụng

  1. Chờ GitHub Pages hoàn tất cập nhật.
  2. Trên máy tính: nhấn Ctrl + F5 để tải lại file mới.
  3. Trên điện thoại: đóng hẳn NgoThang_video rồi mở lại từ biểu tượng màn hình chính. Nếu vẫn thấy giao diện cũ, mở link bằng Safari/Chrome và tải lại.
  4. Tìm thử một từ khóa ngắn, ví dụ nhạc thư giãn.
Đã cập nhật xong. API Key cũ trong config.js vẫn dùng chung cho mọi người; vợ bạn và người khác không cần nhập key riêng.

Nếu vẫn không tìm được video

Bản mới sẽ hiện mã lỗi ở ngay trang kết quả:

  • API_KEY_HTTP_REFERRER_BLOCKED hoặc forbidden: kiểm tra Website restrictions theo Bước 2.
  • accessNotConfigured: bật YouTube Data API v3 trong đúng Project tạo khóa.
  • keyInvalid: kiểm tra khóa trong config.js, còn nguyên dấu ngoặc kép và chưa bị thu hồi.
  • quotaExceeded: đã hết hạn mức tìm kiếm của project.
  • NETWORK_OR_CORS_ERROR: kiểm tra Internet hoặc tiện ích chặn request.

Gửi đường link GitHub Pages và ảnh chụp mã lỗi để kiểm tra tiếp. Không gửi API Key.
